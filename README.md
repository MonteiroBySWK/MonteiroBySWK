- 🚒 **DevOps Reality**: Basically a firefighter putting out production fires — *nowadays, significantly less than it used to be.*

- 🤖 **Agent Wrangler**: Babysitting code agents (they learn ridiculously fast, they just never listen).
- 🎮 **Downtime**: Retro games (Zelda lore), reading and studying weird CS rabbit holes just for fun.
